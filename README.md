# Real-Time-Face-Detection-using-OpenCV
A computer vision project that uses Haar Cascade Classifiers with OpenCV to detect human faces in real time via webcam. This project demonstrates how machine learning can be applied to visual data in an efficient and lightweight manner.

🧰 Tech Stack
Python 3

OpenCV – Image processing and detection

NumPy – Array manipulation


face-detection-ml/

├── generate_dataset.py

├── classifer.py

├── script.py

├── haarcascade_mcs_nose

├── haarcascade_mcs_mouth

├── haarcascade_frontalface_default

├── haarcascade_eye

├── README.md

└── requirements.txt

📌 Key Features
Real-time face detection from webcam input

Draws bounding boxes around detected faces

Uses pre-trained Haar Cascade model for frontal face detection

run as a script (.py)

🚀 How to Run
Clone the repo:
git clone https://github.com/your-username/face-detection-ml.git
cd face-detection-ml

Install dependencies:
pip install -r requirements.txt
Note: You have to also add the haarcascade files to your folder

Run the script in this order:
generate_dataset.py
classifer.py
script.py
Note: Make sure your webcam is enabled and OpenCV is installed properly.
